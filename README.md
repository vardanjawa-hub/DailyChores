# ✅ DailyChores

> All your daily chores on one platform!

A simple, elegant task management web app that helps you organize your daily chores with a warm, cozy aesthetic.

---

## 🌟 Features

- ✅ **Add Tasks** — Quickly add tasks using the input field
- 🗑️ **Delete Tasks** — Remove tasks with the trash icon button
- ☑️ **Mark as Complete** — Check off tasks with a strikethrough effect
- 💾 **Persistent Storage** — Tasks are saved to localStorage and survive page refreshes
- 📅 **Date Tracking** — Every task is stamped with the date it was created
- 🎨 **Cozy UI** — Subtle linen texture background for a tactile, notebook-like feel

## 💡 How It Works

### Adding a Task
- Type your task in the input field
- Click the **+** button to create a card
- Each card shows the **task name** and **creation date**

### Completing a Task
- Click the **checkbox** on any card
- The task text gets a ~~strikethrough~~ to mark it done
- Uncheck to restore it

### Deleting a Task
- Click the 🗑️ button on any card to permanently remove it

### Data Persistence
- All tasks are automatically saved to **localStorage**
- Refreshing or closing the browser will **not** erase your tasks
- Tasks are stored as a JSON string and rebuilt on every page load
